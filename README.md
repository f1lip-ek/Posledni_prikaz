# Poslední příkaz
___
Hra která je na motivy filmu **Matrix**, ale spíš jak to bylo předtím než svět ovládli stroje.
___
## Jak hru spustit
Je treba si otevrit slozku do ktere si stahnes JAR soubor v terminalu.

Pak jen zkopiruj a vloz prikaz dole
```bash
java -jar Posledni_prikaz.jar
```
___
## Prikazy ve hre
```
ls -c - prohledani moznych vychodu

cd <misto> - pohyb do jine mistnosti

get <predmet> - sebrani predmetu

ls -p - zobrazeni vsech moznych predmetu ktere lze sebrat

run <predmet> - pouziti nejakeho urciteho predmetu

cat -i - zobrazeni inventare

kill - timto muzes zabit protivnika kdyz si v boji

exit - timto se muzes vzdat a ummres

ls -q - zobrazeni vsech questu

start

upload

help - vypsani vsech commandu ve hre
```
